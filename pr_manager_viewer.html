บันทึกไฟล์สำรอง (Backup)

ระบบนี้ไม่มีฐานข้อมูลจริง — ข้อมูลทั้งหมดอยู่ใน memory ของเบราว์เซอร์เท่านั้น ถ้าปิดแท็บหรือรีเฟรชหน้า ข้อมูลจะหายทั้งหมด กดปุ่มด้านล่างเพื่อดาวน์โหลดข้อมูลทั้งหมดตอนนี้เป็นไฟล์ .json เก็บไว้ แล้วค่อยนำกลับมาโหลดคืนได้ภายหลัง (ดูหัวข้อกู้คืนด้านล่าง)

.json

ไฟล์สำรองจะรวม: รายการสั่งซื้อที่ยืนยันแล้วทั้งหมด, รายชื่อสาขา, แผนก/ฝ่าย, ผู้จำหน่าย, อัตราภาษี VAT, และหมวดหมู่สินค้า — ไม่รวม ไฟล์ที่ยังค้างอยู่ในคิวหน้า "อัปโหลด/ตรวจสอบ" ที่ยังไม่ได้กดยืนยัน (เพราะเป็นไฟล์ต้นฉบับ ไม่ใช่ข้อมูล ไม่สามารถใส่ในไฟล์ .json ได้ — ถ้ามีไฟล์ค้างอยู่ในคิว แนะนำให้ยืนยันหรือดาวน์โหลดไฟล์ต้นฉบับเก็บไว้เองก่อนปิดหน้าเว็บ)

กู้คืนจากไฟล์สำรอง (Restore)

เลือกไฟล์ .json ที่เคยดาวน์โหลดไว้ เพื่อนำข้อมูลกลับเข้าระบบ เลือกได้ว่าจะ "รวมกับข้อมูลปัจจุบัน" หรือ "ล้างข้อมูลปัจจุบันแล้วแทนที่ทั้งหมด"
